# Defect Type Standard

| Tipo | Nombre | Descripción |
|---|---|---|
| 10 | Documentation | comentarios, mensajes, Javadoc |
| 20 | Syntax | ortografía, puntuación, formato |
| 30 | Build, Package | manejo de versiones, librerías |
| 40 | Assignment | declaración, nombres duplicados, alcance |
| 50 | Interface | llamadas, parámetros, I/O |
| 60 | Checking | mensajes de error, validaciones |
| 70 | Data | estructura, contenido |
| 80 | Function | lógica, apuntadores, ciclos, recursión |
| 90 | System | configuración, tiempos, memoria |
| 100 | Environment | diseño, compilación, pruebas, sistema operativo |
